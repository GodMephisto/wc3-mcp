# 0.5.38 - 2026-11-10

ToolCancellationTests stops cancelling on a one millisecond timer. A fast runner
finished the import before the timer fired, so the expected cancellation never
arrived and the test read as a refusal that never happened. The cancel now fires
from the import's own progress report at the first file, so it lands inside the
run on any machine.

move to 0.5.38.
