# 0.5.45 - 2026-11-25

- Every image decode now runs through one configuration that registers PNG, JPEG, BMP, TGA and GIF only and skips embedded metadata. `TextureConvert` already did that, `AppearanceMetric`, `HeightmapPng` and `PathingPng` still took the default sniffer, which registered a TIFF decoder and read an ICC profile.
- Five open advisories against ImageSharp 3.1.12 sit in its TIFF decoders and encoders and its ICC profile parser, and the release that fixes them, 4.1.1, refuses to build without a Six Labors licence key. The pinned version stays and those code paths stop being reachable from a crafted map file.
- A sixth advisory sits in `HistogramEqualization`, a processing operation nothing in this product calls.
- Four tests hand a real TIFF to `TextureConvert.Convert`, `AppearanceMetric.Compare`, `HeightmapPng.Decode` and `PathingPng.TryDecodeRegion` and expect a refusal, so a caller left on the default configuration fails the suite instead of shipping.
