# 0.5.42 - 2026-11-16

- `repair_reforged3` repairs a legacy SLK map for Warcraft III 3.0 without Devo's Map Doctor, the
  game install or the name dictionary. Model paths move out of the obsolete `file` column of
  `unitUI.slk` and `ItemData.slk` into merged `UnitSkin.txt` and `ItemSkin.txt` profiles, numeric
  cells and button positions are normalized, unmatched FDF comment terminators are removed, and
  abilities declaring more levels than they have columns gain level 5 and 6 columns from level 4.
- `reforged3_check` reports the same six counts read-only, so the size of the repair is known
  before a copy is written.
- Measured on a 101 MB protected campaign map, the repair returned "Runs on Reforged? probably"
  from Devo's doctor with no blockers, the same verdict its own `fix` reaches, while keeping every
  rawcode, every string and every model name. The doctor's fix additionally renames 242 obfuscated
  models to `obf_<hash>` and recompresses the archive. Mine leaves both alone.
- The repair reaches the verdict with no external program at all. `doctor_fix` still calls the
  doctor when it is installed and still refuses with `DOCTOR_NOT_FOUND` when it is not. The native
  path is the one that always works.

Version 0.5.42.
