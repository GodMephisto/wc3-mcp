# 0.5.44 - 2026-11-16

- `texture_audit` reads every texture header in a map and reports the ones the engine mishandles,
  grouped by kind. It checks the BLP signature, that a BLP1 or BLP2 header fits inside the file, that
  a declared JPEG header stays under the 624 bytes the engine allows, that every declared mip level
  ends inside the file, that a chain is not empty, and that dimensions are a power of two. Read-only,
  no game install, no pixel decoded, so the cost is one kilobyte per texture.
- `texture audit` is the same check on the CLI, over a map or over `--dir` of extracted files.
- BLP1 content type 0 is palettized and 1 is JPEG, the opposite of the reading this check first
  shipped. Read the other way, a 10 KB texture War3Net decodes cleanly had its mip tables read 11
  bytes late and every texture in a 768 texture map was reported broken. Measured against the real
  archive, the corrected reading reports none.
- Devo's Map Doctor reports 94 textures on the same map with its own text saying that finding is not
  measured. The headers here are contiguous, end inside the file and leave no level undeclared.
