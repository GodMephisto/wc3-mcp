# 0.5.43 - 2026-11-16

- `game_file_shadows` reports the map files that sit on a path the installed game already ships,
  which makes the engine read the map's copy in place of its own. Devo's Map Doctor names two maps
  that this closed in LAN and HD graphics, one with UI minimap textures and one with 1,486 repacked
  game textures, and removing the files fixed both.
- `repair_game_files` writes a copy with those entries removed, and `repair game-files --apply` does
  the same on the CLI. The archive is rebuilt from disk because `MapDocument` has no delete, so
  every other entry is carried over byte for byte.
- The World Editor's own object data is excluded. A SLK-mode map has to carry `Units\AbilityData.slk`
  and its siblings at the game's paths to define custom objects, so a check that reported them would
  bury the three real overrides under thirty-nine entries. Measured on a 101 MB campaign map, the
  filtered check reports 3 where the unfiltered one reported 39.
- The game list comes from the installed build through CascLib, read per path where the store's
  listfile has no name for a file. A classic-build map can therefore override paths a Reforged
  install has renamed, which the report says rather than hides.
