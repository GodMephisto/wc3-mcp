# UI showcase

---
title: UI showcase
description: Every Warcraft III-themed component this site is built from — courtesy of warcraftcn-ui.
---

This entire site — the nav, the docs shell you're reading, the download button,
the sidebar filter, the cursor — is built from
[warcraftcn-ui](https://github.com/TheOrcDev/warcraftcn-ui) (MIT), a Warcraft
III-inspired component set. Below is a live gallery of every component in it.

<Callout type="info">
  Try the **cursor picker** in the top-right of the nav — it swaps your pointer
  for an orc, human, night-elf, or undead cursor across the whole site.
</Callout>
