## 一、关键 Bug（已修复）

| # | 问题 | 修复 |
|---|------|------|
| 1 | **子级列表未维护** — `inigenerator.cpp` 遍历 `element.children` 但运行时始终为空 | 移除 `children` 字段，改为按 `parent` 字段在导出时动态查找子级 |
| 2 | **导出 Y 坐标计算不一致** — `toWar3Y(element.y, parentY)` 与 X 的 `relX` 预计算模式不一致 | 统一使用 `relY`，内联 Y 转换公式为 `-relY / 1080.0 * 0.6` |

## 二、已完成的新增功能

- **批量属性编辑** — 多选后属性面板进入 batch 模式，修改同步到所有选中元素
- **对齐/分布工具** — 左/右/上/下/水平居中/垂直居中/水平分布/垂直分布，有快捷键
- **最近文件列表** — 存储在 QSettings，最多 9 个，支持清除
- **搜索过滤** — 树面板上方搜索框，按名称大小写不敏感过滤，匹配时展开父级
- **缩放指示器** — 状态栏右侧显示当前缩放百分比
- **Ctrl+Y 重做** — 补充已有的 Ctrl+Shift+Z
- **工具栏图标** — Qt 标准图标 + 工具提示文字
- **CMake 构建** — 支持 CMake 构建（原 qmake 保留），含测试目标
- **单元测试** — 坐标转换、JSON 序列化、循环检测共 12 个测试

## 三、待实现功能

按优先级排序，逐步完成。

### P1 - FDF 导入/导出
Warcraft III 原生 FDF（Frame Definition）格式支持。FDF 是 War3 定义 UI 布局的文本格式，类似 INI 但有更丰富的语法。支持导入已有 FDF 文件和导出当前项目为 FDF。

### P1 - 纹理预览浏览器
在右侧或底部添加一个面板，显示项目中所有已导入纹理的缩略图预览，方便快速查看和选择纹理。

### P1 - Command 模式重构撤销系统
当前使用全量快照（每步存整个元素列表），内存开销大。重构为 Command 模式，每个操作只存增量变化，支持更长的撤销历史。

### P1 - 测试覆盖
补充序列化（JSON 项目文件读写）、INI 导出、撤销操作的核心测试，确保重构时不回退。

### P2 - 标尺与参考线
画布边缘显示标尺，支持从标尺拖出参考线，元素移动时吸附到参考线和其他元素边缘。

### P2 - 元素分组 / 命名空间
支持创建命名分组（类似文件夹），方便管理大量元素。分组不影响导出层级，仅用于编辑时组织。

### P2 - 搜索/替换属性
在属性面板中搜索特定属性值，并支持批量替换。适合在大量元素中统一修改某个纹理路径或文字内容。

### P2 - 模板/预设系统
保存选中的元素为模板，新建时可快速插入预设的 UI 组件（如按钮样式、输入框组合等）。

### P2 - 错误处理改进
项目文件损坏、纹理文件丢失时显示友好的错误对话框，而不是静默失败或崩溃。支持重新定位丢失的纹理。

## 四、构建说明

```bash
# qmake (现有)
qmake6 War3UiBuilder.pro
mingw32-make -f Makefile.Release

# CMake (新增)
cmake -B build -DCMAKE_PREFIX_PATH=D:/Qt/6.10.2/mingw_64
cmake --build build

# 运行测试
ctest --test-dir build
```
