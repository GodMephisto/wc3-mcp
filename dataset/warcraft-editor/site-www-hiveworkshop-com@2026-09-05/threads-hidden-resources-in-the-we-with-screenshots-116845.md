###
 What is this?

This is the list of resources that cannot be viewed in World Editor.

You can view some hidden resources in World Editor if you use World Editor Unlimited or Jass NewGen Pack. This tutorial includes more icons/models than WEU or JNGP.

This tutorial is very useful if you don't use any World Editor addons.

###
 How to use these icons/models

1. Copy custom path of hidden model/icon

2. Open object editor and paste your copied path

Screenshot:

###
 Hidden model/icon doesn't work. What to shall I do now?

1. Make sure that you have copied path correctly

2. Some hidden models are only availible for Frozen Throne, if you want them in your map, ask someone to export them

3. If you have Frozen Throne and copied path correctly, please report it to me here
