How To Fix Custom Disabled Buttons

What is disabled buttons?

Disabled buttons are the icons that become more ''black'' when you see the Quests menu(F9) or the Game Options menu etc.Only for imported icons.

Why Should i Use Them?

Because when you see any kind of menu,if the disabled buttons haven't got the correct path they will turn absolutely green!

So,How can i make them?

Well,first of all when you wanna add a custom icon you downloaded from the internet you have to import both files.The one named BTN(name) and the one called DISBTN(name).Also it may have a little different name(BTNINV)

1.Go to Import Editor or press F12

2.Find out the DISBTN file and change the path to: ReplaceableTextures\CommandButtonsDisabled\(name of icon).blp

3.Then close and open again the World Editor.
