Making custom genre campaign is a possible to make like modern warfare and alien/futuristic campaign but hard. You need for your custom genre campaign you need is skins, models, icons, sounds and musics, UI etc... also external files for your maps and custom game constants, interface and triggered scripts.

Here some steps you make easy to make

1. Import your files needed to your custom genre campaign. If you are just a beginner read first at above.

2. If you want to copy the custom map to add more additional chapter for your custom genre campaign - no problem (but not same information and terrain) - THIS IS TOO EASY

3. If you want to submit your custom genre campaign, please be sure all your used maps are protected from editing.

4. If you want make Credits make sure is cinematic mode at start, special actions and etc...

5. If you want make Free Play make sure is survival game.

6. If you want make Secret Level make sure the game mode is TD or Special Chapter
