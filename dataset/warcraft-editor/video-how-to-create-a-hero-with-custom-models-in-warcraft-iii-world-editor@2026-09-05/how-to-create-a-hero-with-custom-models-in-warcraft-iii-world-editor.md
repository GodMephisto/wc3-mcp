Step by step tutorial

1.Open your world editor
2.Click the object editor or just press F6
3.Click the Create a new custom unit or just press Ctrl+Shift+N
4.Choose your unit/hero make sure you put a name like Blood Mage
5.Minimize Object Editor
6.Go to Import Manager
7.Right click and then click Import file
8.Choose your model you can download models in Hiveworkshop.com
9.Once you have chosen your model save your map so you can prievew the model early
10.Exit Import Manager and then go to Object Editor again

12.Double click Art-Model File and then you can see the import tab click it and find your model once you find your model click ok
