## Description

This video shows how to enable local files in Warcraft III.
What are Local Files? Local Files allow Warcraft III to override the game files with custom files of your choosing. Beside overriding the game files, Local Files can also be used as a custom MPQ for you map/campaign! For example instead of importing the files into the import manager, you could simply put them inside your warcraft III installation and change their path. Although, if you want to use this method (Local Files) instead of the import manager, you will have to provide these files for other people as well so they could play your map/campaign.
